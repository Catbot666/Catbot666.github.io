2025 · NLP / ECONOMICS

LLM-Based Sentiment Analysis for Economic Forecasting

Built a data pipeline spanning more than 100,000 financial-media videos and related comments, combined FinBERT with LLM-based sentiment analysis, and studied the information value of public sentiment for macroeconomic forecasting.

2025 · TRUSTWORTHY AI

TRUSTDA: Dataset Refinement for LLM Evaluation

Co-developed controllable dataset augmentation methods for trustworthiness evaluation. In experiments, average model trustworthiness scores decreased by 12.98% on augmented evaluation data relative to the original dataset.

2025 · MULTI-AGENT RL

Designed modular agent interactions and Python experimentation infrastructure; explored Q-learning and hierarchical reinforcement learning for coordinating privacy-compliance evaluation tasks.
